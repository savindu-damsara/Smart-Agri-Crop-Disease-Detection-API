# Smart-Agri-Crop-Disease-Detection-API

An AI-powered plant disease detection system built using PyTorch,
TensorFlow, FastAPI and computer vision.

## Project Status

🚧 Currently in development.

## Objective

The goal of this project is to develop an end-to-end deep learning
system capable of identifying plant diseases from leaf images.

## Technologies

- Python
- PyTorch
- TorchVision
- TensorFlow
- FastAPI
- Streamlit
- Docker
- GitHub

## Dataset

PlantVillage dataset.

## Planned Features

- Plant disease classification
- Confidence scores
- Top-K predictions
- Explainable AI
- Grad-CAM visualization
- REST API
- Interactive web interface
- Docker deployment
- Cloud deployment
